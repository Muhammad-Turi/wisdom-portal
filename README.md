# Wisdom Portal

Wisdom Portal is a school management app built for my school. It helps staff keep student, teacher, class and fee records in one place, on both Android phones and Windows PCs.

## Features

- Secure login and signup
- Dashboard with school statistics
- Student records and detailed student profiles
- Teacher management
- Class management and class details
- Promote a whole class to the next year
- Graduated students list
- Fee records and purchase tracking
- Works offline, with data syncing when back online
- Responsive layout for phone and desktop screens

## Built with

- Flutter and Dart
- Firebase Authentication
- Cloud Firestore
- Provider (state management)
- window_manager (desktop window control)

## Platforms

- Android
- Windows

## Getting started

1. Install Flutter: https://docs.flutter.dev/get-started/install
2. Clone the repository:

```
   git clone https://github.com/Muhammad-Turi/wisdom-portal.git
   cd wisdom-portal
```

3. Get the packages:

```
   flutter pub get
```

4. Run the app:

```
   flutter run
```

## Build

Android APK:

```
flutter build apk --release
```

Windows app:

```
flutter build windows --release
```

## Installing the app

**Android:** download `app-release.apk`, tap it, and allow installation from unknown sources.

**Windows:** download the zip, extract it fully, then run the exe. If Windows SmartScreen appears, click **More info > Run anyway**.
